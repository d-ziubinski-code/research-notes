# Vulnerable Auth App

A simple web application built to demonstrate **Username Enumeration** and **Password Brute-Force** vulnerabilities.

The project is used to analyze authentication flaws, automate attacks with Python, and inspect HTTP traffic using Burp Suite.

---

### Technical Details

| Feature                  | Description                                                   |
| :----------------------- | :------------------------------------------------------------ |
| **Technologies**         | Python, FastAPI, HTML                                         |
| **Main Vulnerabilities** | Username Enumeration, Missing Rate Limiting / Account Lockout |
| **Testing Tools**        | Burp Suite (Intruder), Custom Python Scripts                  |

---

### Project Structure

```text
demo/
├── main.py

```
